# SAI 0.1.2 — start with a little company

Create a companion or pick up an existing story with one guided command:

```console
python -m pip install sai_companion-0.1.2-py3-none-any.whl
python -m sai start
```

- **An easier first conversation.** Choose an available Claude Code or Codex CLI, name a character, select their relationship and temperament, and add a like or dislike. Existing characters can resume with memories intact. Unfinished setup can be cancelled before saving. The original explicit commands remain available.
- **Room for a real conversation.** Casual dialogue and small suggestions aim for a few concise sentences. Old disagreements need not dominate a new topic; the stored concern still remains until repaired. Requested detailed work is not capped by the casual guidance. These are model instructions, not guaranteed output limits.
- **An everyday demonstration.** The attached 30-second MP4/GIF uses excerpts of actual generated Claude dialogue: a remembered presentation, a small win, a refused cucumber, a return to work and a snack preference. Prompts/replies are excerpted and waiting time is compressed. This is standalone chat playback, not a real-time native-hook recording.
- No runtime dependencies, state migration or automatic host configuration changes. Explicit memories, dislikes, repair rules and OFF behavior are retained. There is no telemetry or new schedule.

You need Python 3.11+ and an installed, signed-in model CLI for live chat. `start` detects executables; login/connection are checked by the first live reply. Existing provider usage applies. `python -m sai demo` remains a separate offline scripted example. `/quit` closes chat; `/sai off` disables the mode while keeping data.

Claude native context/OFF and Codex standalone have project verification records. **Native Codex hook activation remains unverified.** Host instructions can affect language and style; the English recording explicitly requests English without changing host settings.

In the new Codex sample, English replies retained the host's Korean honorific. The strict English-only check therefore remains FAIL, while brevity, explicit memory recall and persistence checks passed. No host instructions were overridden to change this result.

Complete dialogue, failed attempts, installed-wheel checks and media evidence are in [the verification record](https://github.com/TwinPaPas/my-ai-companion/tree/main/docs/verification). These small samples do not prove long-term consistency or user retention.
