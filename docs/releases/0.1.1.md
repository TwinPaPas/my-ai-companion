# SAI 0.1.1 — a little closer, one conversation at a time

A relationship that grows with the AI you already use. A sweetheart to fall for, or a friend to laugh with; a little teasing, a little sulking, and a story that carries into the next session.

- English is now the default for the main README, CLI help/status, care explanations, scripted demo, integration guide, issue forms and release notes. Korean guides remain available.
- A 30-second **edited playback of actual Claude-generated replies** shows a concern surviving a fresh CLI process, flowers failing to erase it, and an apology softening the response. Waiting time is compressed and quotes are excerpted. Full replies and process evidence are published.
- Claude native context/OFF was verified in the initial pilot. Codex standalone chat was verified; native Codex hook activation remains unverified. This distinction is now above installation instructions.
- We are inviting five CLI users to explore what makes them return on their own. Recruitment and feedback instructions are in `docs/PILOT.md`; no participants or retention results are claimed yet.
- Existing state and user-written names/memories are preserved. Generated conversation still follows the user's language within the host's instructions. No new runtime dependencies or state-schema changes.

Install the attached wheel:

```console
python -m pip install sai_companion-0.1.1-py3-none-any.whl
python -m sai demo
```

The MP4/GIF are recorded-dialogue playback assets. `sai demo` is separately labelled scripted and requires no model. Live chat requires an installed, authenticated Claude Code or Codex CLI and consumes its provider usage.

Verification: existing 53-test suite, real English Claude dialogue across fresh processes, a 30-second 1600×900 video, and installed-wheel checks. Detailed results and limits are in `docs/verification/`.
