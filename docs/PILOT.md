# Five CLI users, one simple question

**Does SAI make someone want to open their usual AI CLI again tomorrow?**

We are inviting five adults who already use Claude Code or Codex CLI to try this early pilot. There are no recorded participants or retention results yet. SAI is a fictional companion; this pilot studies whether the interaction is enjoyable, not emotional attachment or psychological outcomes.

## Join

Comment on the [open recruitment post](https://github.com/TwinPaPas/my-ai-companion/issues/1) or open a [pilot experience issue](https://github.com/TwinPaPas/my-ai-companion/issues/new?template=pilot.yml) with the CLI you already use. Use a nickname and fictional example dialogue. No email address, private conversation or state database is needed. The maintainer can agree on participation there; opening an issue alone is not counted as a completed trial.

## First session

1. Install from the README and run `python -m sai start` to create a character or resume one. Record any setup difficulty; CLI detection alone does not verify login.
2. Chat and use a care action during your usual CLI work.
3. Try a disagreement, close the chat process, reopen it, and see whether the same concern remains. Try a relevant apology.
4. Leave honest feedback, including anything dull, artificial or irritating. Use SAI afterwards only when you feel like it.

Claude native hook context/OFF was observed in the initial pilot. Codex standalone chat was observed; native Codex hook activation is still unverified. Participants can use standalone chat with either CLI. Record the route used so those experiences are not confused.
